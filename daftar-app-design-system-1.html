07 — UX Improvements
تحسينات تجربة المستخدم
مقارنة مباشرة مع التطبيقات التقليدية
❌ التطبيقات الحالية
إضافة معاملة تتطلب فتح قائمة → اختيار عميل → فتح نموذج → إدخال بيانات متعددة → حفظ = ٧+ خطوات
✓ دفتر
FAB → اختيار عميل (لمسة واحدة) → لوحة أرقام كبيرة → نوع العملية بـ Chip → حفظ = ٥ ثوانٍ فقط
❌ التطبيقات الحالية
رصيد العميل مخفي داخل جداول وأرقام صغيرة، يصعب قراءته بسرعة
✓ دفتر
الرصيد بارز بـ 36px مع لون معبّر — أحمر للدين، أخضر للسداد — يُقرأ من بعيد في ثانية واحدة
❌ التطبيقات الحالية
التذكيرات تحتاج التنقل عبر قوائم متعددة، لا يوجد عرض موحد للمتأخرين
✓ دفتر
شاشة تذكيرات مخصصة مرتبة بالإلحاحية + زر "إرسال للكل" دفعة واحدة عبر WhatsApp
❌ التطبيقات الحالية
قائمة العملاء خطية متطابقة، يصعب تحديد المتأخرين بنظرة واحدة
✓ دفتر
كل بطاقة عميل تحتوي حالة ملونة + رصيد + آخر معاملة — المسح البصري في 2 ثانية
08 — Microinteractions
الأنيميشن الخفيف
💾
نجاح الحفظ
checkmark يظهر مع دائرة خضراء تمتد من المركز (scale 0→1, duration 300ms, ease-out-back) + اهتزاز خفيف للجهاز (haptic light)
📊
تحديث الرصيد
الرقم يتحرك من القيمة القديمة للجديدة بـ counter animation (duration 600ms, ease-in-out) مع وميض خفيف للبطاقة
💰
إضافة دفعة سداد
عمود الرصيد يتحول من أحمر لأخضر تدريجياً مع أنيميشن تغيير اللون (crossfade 400ms) + نقطة خضراء تومض
🔔
حالة التذكير
أيقونة الجرس تهتز يميناً ويساراً (rotate ±15deg, 3 cycles, duration 400ms) عند إرسال تذكير ناجح
📭
Empty State
الأيقونة تظهر بـ bounce من الأسفل (translateY 30px→0, duration 500ms, spring animation) مع fade-in للنص بتأخير 150ms
+
FAB Button
عند الضغط: + يتحول لـ × مع دوران 45deg (duration 200ms) + Bottom Sheet ينزلق من الأسفل (slide-up 300ms, ease-out)

11 — Figma & AI Prompts
Prompts جاهزة للتنفيذ
🎨 Prompt لـ Figma AI / v0 / Framer AI
Design a modern Arabic RTL fintech mobile app called "دفتر" (Daftar) — a debt/ledger tracking app for small shop owners. Style: Dark mode, Deep Navy background (#0D1117), Teal accent (#0ABFBC), professional fintech aesthetic Font: IBM Plex Sans Arabic, JetBrains Mono for amounts Key screens: Dashboard with KPI cards, Client list with status badges, Transaction bottom sheet with numpad Design principles: - RTL layout, Arabic text - Large bold numbers for amounts (Monospace font) - Color coding: red (#E8524A) for debt, green (#2DCE89) for payment - Elevated card layers: #0D1117 → #161B22 → #1C2230 → #232B3E - FAB button for quick transaction entry - Bottom sheet for adding transactions (5-second flow) - Timeline view for client transaction history - Segmented control for filtering (الكل / عليهم / مسددين)
📱 Prompt لكل شاشة — Dashboard
Arabic RTL mobile dashboard screen, dark navy background (#0D1117). Top: greeting + date. Main card: gradient dark surface showing total receivable in large green monospace number (١٢,٤٥٠ ر.س), secondary stats below. 2-column KPI grid: today's transactions (green), pending reminders (red). Recent transactions list: avatar circle + name + date + colored amount. Bottom: teal CTA button "إضافة معاملة". Bottom navigation bar with 5 icons. No clutter, strong visual hierarchy, fintech premium feel.
📱 Prompt لكل شاشة — إضافة معاملة
Arabic RTL mobile "Add Transaction" screen, dark mode. Top: selected client card with current balance. Operation type selector: 2 large chips "له عليّ" (red-tinted) / "عليه لي" (green-tinted). Center: huge monospace amount display (52px) with currency label. Custom Arabic numpad grid (3x4), rounded keys. Bottom: inline note + date inputs side by side. Fixed CTA button showing operation summary: "تسجيل — له عليّ ٣٥٠ ر.س". The amount input should feel like a calculator — fast, tactile, no keyboard popup.
📱 Prompt لكل شاشة — تفاصيل العميل
Arabic RTL mobile client detail screen, dark navy fintech style. Header card: large avatar (60px rounded), client name, phone, HUGE balance number (36px bold monospace) in red if debt/green if paid, status badge. Quick action grid: 4 buttons in 2x2 layout (إضافة دين/تسجيل سداد/إرسال تذكير/تعديل) — color-coded. Transaction timeline below: vertical line with colored dots (red=debt, green=payment), each item is a colored card showing type + amount + date + note. Clean, scannable, action-oriented layout.
